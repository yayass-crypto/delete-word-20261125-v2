## Entry

One word, nothing else: **hippopotomonstrosesquippedaliophobia** (36 characters).

The joke is the word itself: the clinical name for the fear of long words is itself a terrifying 36-letter word. Deleting it is the cure for the condition it names — a reader gets it the moment they see how long the word is, with no caption needed.

## How it works

`main.py` writes exactly that one word to `/output/entry.txt` (UTF-8, 1–77 characters, not only whitespace — the competition gate), after validating length, single-word form, and UTF-8 encodability.
